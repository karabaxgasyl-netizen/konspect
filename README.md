# Конспект: школьные учебники в трёх уровнях

Статический образовательный сайт (HTML + CSS + JavaScript), готовый для публикации через GitHub Pages. Все три уровня каждого параграфа — «Кратко», «Средне» и «Подробно» — представлены связным сплошным текстом, как устный ответ ученика, без маркированных и нумерованных списков внутри пересказов.

## Учебники в библиотеке

- `data/geography-9.json` — география, 9 класс, 57 параграфов; все три уровня переведены в формат связного пересказа.
- `data/history-9-medinsky.json` — всеобщая история, 9 класс, 23 параграфа.
- `data/physics-9-peryshkin.json` — физика, 9 класс, 67 параграфов.
- `data/social-9-medvedev.json` — обществознание, 9 класс, 19 разделов.
- `data/biology-9-pasechnik.json` — биология, 9 класс, 49 параграфов.
- `data/chemistry-9-gabrielyan.json` — химия, 9 класс, 41 параграф.

Всего: 6 предметов и 256 параграфов/разделов. Каждый материал содержит самостоятельные версии трёх уровней подробности.

## Структура проекта


## Публикация на GitHub Pages

1. Распакуйте архив.
2. Откройте папку `site` и загрузите **всё её содержимое** в корень репозитория GitHub (не загружайте саму папку `site` как вложенную папку).
3. Подтвердите изменения кнопкой **Commit changes**.
4. В репозитории откройте **Settings → Pages**. В Source выберите **Deploy from a branch**, Branch — `main`, Folder — `/ (root)`, затем нажмите **Save**.
5. После публикации сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.
6. На телефоне сайт можно добавить на главный экран через меню браузера: Safari → «Поделиться» → «На экран Домой» или Chrome → «Установить приложение».

Если после загрузки показывается старая версия, обновите страницу без кеша или закройте и заново откройте вкладку. Версия service worker обновлена для загрузки новых файлов данных.

## Формат данных

Каждый JSON учебника содержит массив `paragraphs`. У каждого параграфа есть `prose.short`, `prose.medium` и `prose.detailed`. Каждое поле — одна строка связного текста. Интерфейс выводит её в одном абзаце и позволяет переключаться между уровнями без перезагрузки страницы.
